# Projeto — Recriação Responsiva Spotify

## Autor

José Humberto Cavalcanti Gomes

## Site Escolhido

Spotify

## Link do Site Original

https://open.spotify.com/intl-pt

## Objetivo

Desenvolver uma homepage responsiva inspirada no Spotify utilizando apenas HTML e CSS.

## Tecnologias Utilizadas

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- clamp()
- prefers-color-scheme

## Estratégia Responsiva

Mobile First

## Breakpoints

- 768px
- 1024px
- 1440px

## Adaptações Realizadas

A homepage foi simplificada para fins educacionais, mantendo os principais conceitos visuais do Spotify.

## Dificuldades

Organização dos cards responsivos e adaptação do layout para diferentes tamanhos de tela.
