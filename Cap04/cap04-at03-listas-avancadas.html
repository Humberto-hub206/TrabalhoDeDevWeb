2. Ranking de Tecnologias

  1. Angular

    Framework completo para aplicações robustas, muito usado em grandes projetos.

  2. Vue.js

    Framework progressivo e fácil de aprender, bastante utilizado em interfaces modernas.

  3. React

    Biblioteca popular para construção de interfaces dinâmicas baseada em componentes.

  4. JavaScript

    Linguagem essencial para adicionar interatividade e lógica às páginas web.

  5. HTML & CSS

    Base do desenvolvimento web, responsáveis pela estrutura e estilo das páginas.

3. Glossário Técnico

HTML
Linguagem de marcação utilizada para estruturar páginas web.
CSS
Responsável pela estilização visual das páginas web.
JavaScript
Linguagem de programação usada para interatividade no navegador.
Pode ser executada tanto no frontend quanto no backend (Node.js).
DOM
Representação em árvore da estrutura de uma página HTML.
API
Interface que permite comunicação entre diferentes sistemas.
Pode ser usada para consumir dados de serviços externos.
HTTP
HTTPS
Protocolos de comunicação utilizados para transferência de dados na web.
URL
Endereço Web
Localização de um recurso na internet.
DNS
Sistema que traduz nomes de domínio em endereços IP.
