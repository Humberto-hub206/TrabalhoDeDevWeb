## Tema
Editorial Dark Minimalista

## Design de Referência
Design 138 — CSS Zen Garden

## Link de Referência
https://csszengarden.com/138/

## Descrição
O projeto foi inspirado no design 138 do CSS Zen Garden, seguindo uma proposta visual editorial minimalista com foco em tipografia forte, contraste e legibilidade.

A estrutura principal foi desenvolvida utilizando CSS Grid, enquanto Flexbox foi aplicado em componentes internos e elementos de navegação.

O layout utiliza uma paleta escura sofisticada, destaques em roxo e azul e responsividade para dispositivos móveis.

## Recursos Utilizados
- CSS Grid
- Flexbox
- Variáveis CSS
- Media Queries
- Google Fonts
- Position Sticky
- Pseudo-classes :hover
- Responsividade
